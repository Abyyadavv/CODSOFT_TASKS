CodSoft Frontend Development Internship

This repository contains the projects completed during my CodSoft Frontend Development Internship.

The tasks were developed using HTML, CSS, and JavaScript**, with a focus on responsive design, interactive user interfaces, and practical frontend development.

📌 Tasks Completed

Task 1 — Personal Portfolio

A responsive personal portfolio website showcasing my profile, skills, projects, and professional information.

Technologies:HTML, CSS, JavaScript

Task 2 — To-Do List App

A simple and interactive To-Do List application for adding, managing, and completing daily tasks.

Technologies:HTML, CSS, JavaScript

Task 3 — Expense Tracker

An expense tracking application designed to record expenses and manage personal spending through an interactive interface.

Technologies:HTML, CSS, JavaScript

Task 4 — Music Player

A browser-based music player with an interactive interface for playing and controlling music.

Technologies: HTML, CSS, JavaScript

Task 5 — Blog Website

A responsive blog website with a clean layout for presenting blog content and creating an engaging reading experience.

Technologies:HTML, CSS, JavaScript
