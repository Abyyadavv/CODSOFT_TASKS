# The Daily Edit — Blog Website

A responsive blog website featuring articles on technology, design, lifestyle, and productivity.

## Features

* Modern, responsive homepage
* Featured blog story
* Blog cards with images, titles, descriptions, and publication dates
* Category-based article filtering
* Search functionality
* Individual article reading interface
* Light and dark mode
* Responsive navigation
* Clean footer design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension if it is not already installed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
